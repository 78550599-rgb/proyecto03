# Proyecto 03 · Mini web personal

Práctica de la semana 10 con HTML, CSS, JavaScript y Git.

## Ver la página

Abre `index.html` en un navegador moderno. No necesita instalación ni conexión.
Pulsa **Saludar**: aparecerá un mensaje en la página. El mensaje también es
accesible mediante lectores de pantalla. Las animaciones respetan la preferencia
de movimiento reducido.

## Archivos

- `index.html`: contenido y estructura de la página.
- `style.css`: diseño adaptable a móviles, colores y animaciones.
- `script.js`: mensaje de consola y acción del botón.

## Historial de Git

Los commits muestran la construcción progresiva desde «Hola mundo» hasta la
versión final. Se revisaron los cambios antes de guardar cada versión.
